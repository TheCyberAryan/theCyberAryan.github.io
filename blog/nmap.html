Nmap — Zero to Hero (Elite Pentesting & Recon Guide)

Author: Aryan Pareek • Date: 2025-11-17 • Category: Scanning & Enumeration

Nmap is the king of network scanning. It discovers hosts, services, ports, versions, operating systems, vulnerabilities, misconfigurations and network fingerprints. This guide takes you from absolute beginner to expert with real commands, examples, workflows, and bug-bounty ready scans.

🚀 What is Nmap?

Nmap (Network Mapper) is a reconnaissance and port-scanning tool used to discover open ports, services, firewalls, OS fingerprints, and vulnerabilities during pentesting and bug bounty assessments. 

Open Ports → Services → Versions → OS → Vulnerabilities

Nmap helps you identify:

  • Open ports & listening services
  • Running software & versions
  • Firewall rules & filtering
  • OS & device fingerprinting
  • Vulnerabilities via NSE scripts

⚙️ Installation

sudo apt install nmap
# or
brew install nmap

🔰 Basic Scans

Scan a single target

nmap example.com

Scan multiple targets

nmap 192.168.1.1 192.168.1.20 example.com

Scan a whole subnet

nmap 192.168.1.0/24

🟣 Service & Version Detection

nmap -sV example.com

Aggressive service detection

nmap -A example.com

🟣 Fast Scanning

nmap -T4 example.com
nmap --top-ports 100 example.com

🛡️ Firewall / Stealth Scanning

nmap -sS example.com
nmap -f example.com
nmap -Pn example.com

🧠 OS Fingerprinting

nmap -O example.com

🧪 Vulnerability Scanning (NSE)

Run default script scan

nmap -sC example.com

Vulnerability category scan

nmap --script vuln example.com

Specific NSE script

nmap --script http-title example.com

🔍 Enumerating Web Servers

nmap -p 80,443 -sV --script http-enum example.com

🔍 Enumerating SMB

nmap -p 445 --script smb-enum-shares example.com

🔍 Enumerating FTP

nmap -p 21 --script ftp-anon example.com

🥷 Bug Bounty Recon Workflow

1. Fast scan for alive ports

nmap -T4 --top-ports 100 example.com -oN quick.txt

2. Full detailed scan

nmap -A -p- example.com -oN full.txt

3. Vulnerability scripts

nmap --script vuln example.com -oN vuln.txt

4. Combine with other tools

subfinder -d example.com -o subs.txt
httpx -l subs.txt -o live.txt
nmap -p- -sV -iL live.txt -oN services.txt
Tip: Run Nmap on specific high-value ports you discover with Naabu or Masscan for deeper enumeration.

Conclusion

Nmap is the backbone of network reconnaissance. Learn its flags, understand its techniques, and integrate it into automated recon pipelines to uncover services, vulnerabilities, and attack surfaces with precision.
