Nuclei — Zero to Hero Guide

Author: Aryan Pareek • Date: 2025-11-17 • Category: Vulnerability Scanning

Nuclei is a high-speed, template-based vulnerability scanner built by ProjectDiscovery. It powers modern bug bounty and enterprise security automation with unmatched flexibility.

Why Nuclei?

  • Runs thousands of checks at enterprise speed
  • Uses YAML templates for everything — simple but powerful
  • Massive community template library
  • Integrates perfectly into recon pipelines
  • Ideal for automation & CI/CD
Input: URLs, IPs, CIDRs  
Output: Vulnerabilities, exposures & metadata

Installation

sudo apt install nuclei
curl -s https://api.projectdiscovery.io/tools/install | sh
brew install nuclei

Update Templates

nuclei -update-templates
nuclei -version

Basic Usage

nuclei -u https://example.com
nuclei -l urls.txt -o nuclei_out.txt

Template Tags

cves  
misconfig  
tokens  
exposures  
network  
dns  
cloud

Run specific categories

nuclei -l urls.txt -tags cves,misconfig -o out.txt

Output Formats

nuclei -l urls.txt -o out.txt       # plain  
nuclei -l urls.txt -json -o out.json  
nuclei -l urls.txt -me report.md

Rate Limits & Concurrency

nuclei -l urls.txt -rl 50  
nuclei -l urls.txt -c 50

Severity Filtering

nuclei -l urls.txt -severity high,critical -o high.txt

Exclude Noisy Templates

nuclei -l urls.txt -exclude-tags fuzz,bruteforce

Workflows

nuclei -l urls.txt -w workflows/scan-admins.yaml -o workflow_out.txt

Custom Template Example

id: exposed-git
info:
  name: Exposed .git HEAD
  severity: medium
requests:
  - method: GET
    path:
      - "{{BaseURL}}/.git/HEAD"
    matchers:
      - type: word
        words:
          - "ref: "

Authenticated Scanning

nuclei -l urls.txt -H "Authorization: Bearer TOKEN"

Real Recon Pipeline

subfinder -d example.com -o subs.txt  
httpx -l subs.txt -o alive.txt  
naabu -list alive.txt -o ports.txt  
nuclei -l alive.txt -severity medium,high -o nuclei_results.txt
Pro Tip: Update templates daily — new CVEs appear constantly.

Common Template Features

  • Matchers (word, regex, binary, status)
  • Extractors (response data capture)
  • Payloads for fuzzing
  • Conditions for complex chains

Template Debugging

nuclei -t templates/exposed-git.yaml -u https://example.com -debug

Reducing False Positives

  • Combine matchers
  • Use length matchers when possible
  • Confirm with Httpx or Nmap

CI/CD Integration

- name: Run nuclei  
  run: |  
    nuclei -update-templates  
    nuclei -l urls.txt -severity medium,high -o nuclei_run.json

Use Cases

Quick High Severity Sweep

nuclei -l alive.txt -severity high,critical -o high.txt

Moderate Full Scan

nuclei -l alive.txt -c 50 -rl 100 -o all.txt

Web Focused Only

nuclei -l urls.txt -tags exposures,technologies -o web.txt

Conclusion

Nuclei is a world-class scanning engine — flexible, scalable, and perfect for automation. With custom templates and controlled workflows, it becomes an unstoppable tool in any offensive security workflow.
