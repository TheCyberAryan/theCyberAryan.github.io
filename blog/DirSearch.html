Dirsearch – Zero to Hero (Full Practical Guide)

A beginner-friendly, clean explanation of Dirsearch, one of the most powerful directory enumeration tools for cybersecurity and bug bounty hunters.

🔥 What is Dirsearch?

Dirsearch is a directory and file brute-forcing tool designed to uncover hidden paths on a website—paths developers forgot to remove, restrict, or secure.

/admin
/login
/backup
/dev
/test
/.git
/config.php
/server-status

These endpoints often reveal:

  • Admin dashboards
  • Credentials
  • Database dumps
  • Configurations
  • Internal test environments

⚙️ Installation

Clone the repository

git clone https://github.com/maurosoria/dirsearch.git
cd dirsearch

Run it

python3 dirsearch.py -u https://example.com

🔰 Basic Usage

Scan one URL

python3 dirsearch.py -u https://example.com

Save output

python3 dirsearch.py -u https://example.com -o result.txt

Increase threads (speed)

python3 dirsearch.py -u https://example.com -t 50

🔎 Intermediate Usage

Use a custom wordlist

python3 dirsearch.py -u https://example.com -w wordlist.txt

Scan multiple targets

python3 dirsearch.py -L targets.txt

Add file extensions

python3 dirsearch.py -u https://example.com -e php,js,txt

Recursive scanning

python3 dirsearch.py -u https://example.com -r

Exclude status codes

python3 dirsearch.py -u https://example.com --exclude-status 403,404

Show only interesting responses

python3 dirsearch.py -u https://example.com -i 200,204,301,302

🚀 Advanced Usage

Use custom headers (JWT, Cookies, Tokens)

python3 dirsearch.py -u https://example.com -H "Authorization: Bearer TOKEN"

Use proxy (BurpSuite)

python3 dirsearch.py -u https://example.com --proxy http://127.0.0.1:8080

Ignore SSL errors

python3 dirsearch.py -u https://example.com --ignore-ssl-errors

Force extension brute-forcing

python3 dirsearch.py -u https://example.com --force-extensions

Filter by response size

python3 dirsearch.py -u https://example.com --min-size 200 --max-size 8000

🧪 Real Bug Bounty Recon Workflow

1. Subdomain Enumeration

subfinder -d example.com -o subs.txt

2. Check which ones are alive

httpx -l subs.txt -o live.txt

3. Run Dirsearch on all live hosts

while read url; do
  python3 dirsearch.py -u $url -e php,txt,js -r -t 50 -o results/$url.txt
done < live.txt

📚 Quick Cheat Sheet

Basic scan: -u
Wordlist: -w FILE
Extensions: -e php,js,txt
Recursive: -r
Exclude: --exclude-status
Interesting: -i 200,301
Proxy: --proxy
Ignore SSL: --ignore-ssl-errors
Output: -o file.txt
