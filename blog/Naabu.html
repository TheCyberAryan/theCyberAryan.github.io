Naabu — Zero to Hero (High-Speed Port Scanning for Recon & Pentesting)

Author: Aryan Pareek • Date: 2025-11-17 • Category: Recon / Port Scanning

Naabu is a blazing-fast port scanner developed by ProjectDiscovery. It is designed to find open ports across large attack surfaces with speed, accuracy, and stealth. This Zero-to-Hero guide covers installation, beginner commands, advanced usage, stealth mode, evasion, automation, and real bug bounty workflows.

🔥 What is Naabu?

Naabu performs asynchronous TCP SYN scans to detect open ports quickly and reliably. It’s commonly chained with Subfinder, Httpx, Dirsearch, and Nuclei in modern recon pipelines.

Input: Domains / IP ranges
Output: Open ports + services

⚙️ Installation

sudo apt install naabu
# or
curl -s https://api.projectdiscovery.io/tools/install | sh

🔰 Basic Usage

Scan a domain

naabu -host example.com

Scan an IP

naabu -host 192.168.1.1

Scan a list of domains

naabu -list hosts.txt -o ports.txt

🟣 Port Selection

Scan top 100 ports

naabu -host example.com -top-ports 100

Scan all ports (1–65535)

naabu -host example.com -p -

Scan custom ports

naabu -host example.com -p 80,443,21,22,8080

⚡ Speed & Performance

Increase speed (threads)

naabu -host example.com -rate 50000

Avoid packet drops

sudo sysctl -w net.ipv4.ping_group_range='0 2147483647'

🛡️ Stealth & Firewall Evasion

Use SYN scan (default)

naabu -host example.com -s

Use connect scan (bypasses some firewalls)

naabu -host example.com -connect

Use fragmented packets

naabu -host example.com -f

🔒 Excluding Ports / Protocols

naabu -host example.com -exclude-ports 80,443

🔍 Service detection (integrated with Nmap)

naabu -host example.com -nmap

Run Nmap automatically after detecting open ports

naabu -host example.com -nmap-cli "-sV -sC"

📡 Host Discovery

naabu -host example.com -p 80,443,22 -host-discovery

🧪 Real Recon Workflow

1. Subdomains

subfinder -d example.com -o subs.txt

2. Filter alive hosts

httpx -l subs.txt -o alive.txt

3. Find open ports with Naabu

naabu -list alive.txt -p - -o open_ports.txt

4. Run Nmap for deep service detection

nmap -sV -sC -iL open_ports.txt -oN nmap_results.txt

5. Directory discovery

while read url; do
  python3 dirsearch.py -u $url -e php,js,txt -r -t 50
done < alive.txt

6. Vulnerability scanning

nuclei -l alive.txt -severity medium,high,critical -o nuclei_results.txt
Pro Tip: Naabu + Nmap is the elite combination for infrastructure-level recon.

Conclusion

Naabu is a high-speed, modern port scanner crafted for bug bounty recon and pentesting. When combined with Httpx, Nmap, Subfinder, Dirsearch, and Nuclei, it forms one of the most powerful recon pipelines in the world. Master the flags, control the rate, and use Naabu responsibly within scope.
